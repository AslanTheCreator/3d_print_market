Совпадает ли это правило с пользовательской прямой отменой только из `BOOKED` или административная матрица отличается?
- **Ответ:** только BOOKED → CANCELLED, заказ принадлежит указанному боту, запись в административную историю. Отдельный ADMIN endpoint сохраняется; покупатель заказа бота может пользоваться своим пользовательским endpoint из BOOKED.
- **Этап:** 2 — окончательная матрица административного CANCEL и её acceptance-проверки.
- **Статус:** закрыт, временная политика заменена подтверждённой в этапе 2.
