# Заметки по UI

## Форма добавления адреса при оформлении заказа

Нужно отдельно продумать UI формы добавления адреса, особенно на мобильных экранах.

При дальнейшей доработке оценить:

- расположение и порядок полей на узком экране;
- высоту формы, прокрутку и поведение при открытой экранной клавиатуре;
- доступность кнопок «Сохранить и использовать» и «Отмена»;
- понятность переходов между списком адресов, формой, сохранением и ошибкой.

Это заметка для дальнейшего обсуждения, а не согласованный план редизайна.
